# Читаемые скрипты и тестовые helpers

## Why

[#62](https://github.com/antonsmolko/gost-spec/issues/62) просит сделать проверки
репозитория понятной последовательностью операций. Сейчас основные проверки
смешивают обход файлов, чтение metadata и формирование диагностик во вложенных циклах.

## What Changes

- Проверить все два скрипта и три модуля `tests/helpers/`; выделить именованные
  шаги там, где это улучшает чтение. Простые helpers сохранить без искусственного дробления.
- Сохранить результаты, порядок ошибок, CLI и побочные действия; подтвердить
  совместимость существующими тестами и точечными проверками границ.
- Оценить повторения identity в связанных тестах, сохранив независимые ожидания.

## Capabilities

Новых или изменённых требований нет: чистый рефакторинг, `skip_specs: true`.
Контракты поставки и содержимого пакетов сохраняются.

## Impact

`scripts/`, `tests/helpers/`, необходимые поведенческие тесты и документация
сопровождения. Перенос тестов — отдельная #63; содержимое плагинов, версии,
нормативные статусы, release gates и зависимости не меняются.
